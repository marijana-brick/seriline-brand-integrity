# Brand intake — evidence extraction

Use this when no completed company brand profile exists.

1. **Collect** the official brand guide, current logos, source design tokens, 2–4 strong examples across intended channels and approved copy examples. Ask for assets only if not accessible.
2. **Extract** a source-backed visual inventory: names and real values, plus links or file paths. Distinguish design-system values from accidental styling in one screenshot.
3. **Extract voice** from actual first-party writing: rhythm, vocabulary, specificity, restraint, sentence structure, CTA convention and taboo claims. Quote short supporting examples internally when permissible.
4. **Identify** what is distinctive and purposeful. Separate identity anchors (must remain recognizable) from channel conventions (may flex).
5. **Resolve conflicts** using authority, recency, channel and owner; list unresolved conflicts rather than silently guessing.
6. **Write** the profile and attach a source ledger with verification dates. Mark every conjectural decision INFERRED or TBD.
7. **Test** on two divergent outputs (e.g. deck slide and email, or dashboard and PDF). The results should feel related without being mechanically identical.

Minimum viable intake when time is short: official logo, typeface, brand color roles, three authentic visual references, three authentic copy samples, and audience/product positioning. If unavailable, make provisional output rather than declaring new guidelines.
